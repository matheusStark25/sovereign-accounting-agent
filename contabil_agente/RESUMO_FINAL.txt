🚀 COMO USAR AGORA:

  PASSO 1: Configure a API Key do GROQ
  ────────────────────────────────────────────────────────────────────
  1. Acesse: https://console.groq.com/keys
  2. Faça login ou crie uma conta
  3. Clique em "Create API Key"
  4. Copie a chave (começa com gsk_)
  5. Execute:
     
     cd "c:\Users\User\Desktop\agent projeto V2\contabil_agente"
     notepad .env
  
  6. Substitua esta linha:
     GROQ_API_KEY=your_groq_api_key_here
  
     Por:
     GROQ_API_KEY=gsk_sua_chave_real_aqui
  
  7. Salve (Ctrl+S) e feche


  PASSO 2: Teste a Configuração (Opcional)
  ────────────────────────────────────────────────────────────────────
  .\testar_configuracao.ps1
  
  → Verifica se tudo está OK antes de iniciar


  PASSO 3: Inicie o Servidor
  ────────────────────────────────────────────────────────────────────
  .\iniciar_servidor.ps1
  
  → Aguarde ver: "Running on http://0.0.0.0:5000"
  → NÃO FECHE esta janela!


  PASSO 4: Acesse a Interface
  ────────────────────────────────────────────────────────────────────
  Abra seu navegador em:
  
  http://localhost:5000/adaptada
  
  → Interface deve carregar instantaneamente
  → Status deve mostrar: "Sistema Conectado ✓" (verde)


  PASSO 5: Teste o Chat
  ────────────────────────────────────────────────────────────────────
  1. Digite: "Olá, você está funcionando?"
  2. Pressione Enter
  3. Veja a resposta da IA em segundos
  4. Teste trocar entre perfis (👔 🌾 👴)

🎨 COMO A COMUNICAÇÃO FUNCIONA:

  1. Usuário digita mensagem no HTML
     ↓
  2. JavaScript captura e envia via fetch()
     POST → http://localhost:5000/api/chat
     Body: { mensagem: "...", session_id: "..." }
     ↓
  3. Backend Flask recebe em routes/chat.py
     ↓
  4. Backend processa e consulta GROQ API
     ↓
  5. Backend retorna JSON
     { resposta: "...", pensamento: "...", pdf_url: "..." }
     ↓
  6. Frontend recebe e exibe resposta
     ↓
  7. PDF é adicionado se disponível

❗ PROBLEMAS?

  Servidor não inicia?
  ────────────────────────────────────────────────────────────────────
  .\diagnosticar.ps1
  → Identifica e sugere soluções automaticamente

  API Key não funciona?
  ────────────────────────────────────────────────────────────────────
  1. Verifique se começa com "gsk_"
  2. Confirme que tem ~52 caracteres
  3. Teste em: https://console.groq.com/playground

  Interface não carrega?
  ────────────────────────────────────────────────────────────────────
  1. Confirme URL: http://localhost:5000/adaptada
  2. Verifique se servidor está rodando
  3. Limpe cache do navegador (Ctrl+F5)

  Status mostra "Offline"?
  ────────────────────────────────────────────────────────────────────
  1. Teste: curl http://localhost:5000/api/health
  2. Veja logs no terminal do servidor
  3. Verifique se porta 5000 está livre:
     netstat -ano | findstr :5000
